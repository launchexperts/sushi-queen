Our story

A neighbourhood sushi bar, run with pride.

Sushi Queen started as a single counter with one rule — never serve a roll we wouldn't eat ourselves. We keep the menu small so we can keep the quality high, slicing fish to order all day, every day.

  • ✓ Rice seasoned and rolled fresh each morning
  • ✓ Premium, sustainably sourced fish
  • ✓ Gluten-free and vegetarian options always available
  • ✓ Family-owned and proudly local
